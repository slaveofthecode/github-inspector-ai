What is GitHub Inspector?

GitHub Inspector is a developer tool that turns a raw GitHub account into a readable snapshot of its work. It lists public repositories sorted by creation date and, for each one, surfaces the top 5 programming languages, its description, and its creation and last-commit dates — everything you need to understand a developer's stack in seconds.

Key features

Designed to make repository discovery fast, clear, and pleasant.

Search

URL or username

Paste https://github.com/microsoft or just microsoft — the account is validated and extracted automatically.

Insights

Top languages per repo

The five most-used technologies of every repository, based on real byte usage from the GitHub API.

Metadata

Key dates at a glance

Creation and last-commit dates on every card, so you can judge activity and project maturity quickly.

Browsing

Infinite scroll

Results stream in as you scroll — no pagination fatigue for accounts with many repositories.

How it works

One input, three steps, instant results.

1

Enter a GitHub account

Type a profile URL or username. Input is validated client-side with Zod for instant feedback.

2

Fetch from GitHub

The server queries the GitHub API for public repositories and the top languages of each one.

3

Read the overview

Results render as styled cards sorted by creation date, with infinite scroll as you browse.
